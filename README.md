# UserManagement
A simple usermanagement application which uses Angular for frontend and Java springboot for backend and api handling.
In this application we can able to handle users and perform operations like adding user, edit user and delete user.
You can manage in the frontend UI related to user management, from where the API calls will hit the Java springboot tomcat backend server for the respective operations.
I have used MYSQL database to store the user data.
